¿Que es PHP?  
R/= Es un lenguaje de código abierto que se utiliza principalmente para el
desarrollo web y que permite por ende crear paginas web sin necesidad
de tener tanto conocimiento gracias a su flexibilidad.
  ****
¿Para que nos sirve un Foreach?  
R/= Este nos sirve como un bucle en el cual hace un recorrido de los 
elementos que se encuentran dentro de ella o le podemos llamar 
coleccion y eso nos permite hasta cierto punto poder tener varias ejecuciones
dentro de ella.
****

R/= Interpretado.

¿Para qué nos serviría usar PHP?
